# components/

Reusable, presentational UI pieces shared across pages — cards, tables, form
fields, modals, nav bars, chart wrappers, etc. Not tied to a single route.

`components/ui/` holds shadcn/ui primitives generated by `npx shadcn@latest add
<component>` (e.g. `button.tsx`). Do not hand-edit generated primitives beyond
what shadcn itself writes; compose them from feature components instead.

Nothing in here should call `services/*` directly with business logic baked
in — fetch data in a page/hook and pass it down as props, so components stay
reusable and testable.
